Conventions, as in the course text: log n means log₂ n unless stated; the height of a tree counts the nodes on its longest root-to-leaf path, so the empty tree has height 0; O(g), Ω(g) and Θ(g) are sets of functions, and f ∈ O(g) is the precise statement that f = O(g) abbreviates.
