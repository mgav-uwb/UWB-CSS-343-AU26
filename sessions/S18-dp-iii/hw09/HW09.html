Homework 9: Knapsack, Edit Distance and Matrix Chains

In 1978 Ralph Merkle and Martin Hellman built a public-key cryptosystem on the knapsack problem. Adi Shamir broke it in 1982. A. Shamir, “A Polynomial Time Algorithm for Breaking the Basic Merkle-Hellman Cryptosystem,” FOCS 1982
At a glance
Covers: Lecture 17 (Dynamic Programming II) and Lecture 18 (Dynamic Programming III) Format: individual Language: C++17 Starter: hw09.cpp Submit: a .zip with your hw09.cpp Due: Sun Dec 6, 11:59 PM

Five functions: the full 0/1 knapsack table, the items an optimal knapsack takes (found by walking the table back from its answer cell), the edit distance between two strings, the knapsack's optimal value computed in a single row of memory, and the cheapest way to parenthesize a chain of matrix multiplications. The starter has a self-running test battery; you fill in five TODOs. Quiz 8 (Monday Dec 7) covers this material too.

Tasks

TODOFunctionWhat it must do
1knapsackTableFill the whole 0/1 knapsack table: one row per item added, one column per capacity from 0 to W.
2knapsackItemsRecover which items an optimal knapsack takes, by comparing each cell with the one above it on a walk back from the answer cell.
3editDistanceThe fewest single-character inserts, deletes and replaces that turn one string into another.
4knapsackOneRowThe knapsack's optimal value in one row of W + 1 entries, swept from high capacities to low.
5matrixChainThe fewest scalar multiplications needed to multiply a chain of matrices, by an interval DP filled in order of range length.

The full contract of each function, with examples, is in the comment above it in the starter. Every function is also tested on large inputs with a time limit (a table of 10 million cells, strings of 3,000 characters, 400 matrices), and knapsackOneRow with a memory limit as well: write each one with the running time and memory its contract states.

The tests run themselves

g++ -std=c++17 -O2 hw09.cpp -o hw09 && ./hw09

Each check prints [PASS] or [FAIL]. The unmodified starter compiles and fails all of them.
