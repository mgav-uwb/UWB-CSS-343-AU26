Homework 10: Tries, Substring Search and Regular Expressions

grep is named after the ed editor command g/re/p: globally search for a regular expression and print the matching lines. Brian Kernighan, UNIX: A History and a Memoir, 2019
At a glance
Covers: Lecture 19 (Strings: Tries and Substring Search) and Lecture 20 (Regular Expressions and Finite Automata) Format: individual Language: C++17 Starter: hw10.cpp Submit: a .zip with your hw10.cpp Due: Fri Dec 11, 11:59 PM (no late tokens)

Seven functions: insertion into an R-way trie that reports how many nodes it allocated, the longest stored key that is a prefix of a query, the Knuth-Morris-Pratt (KMP) failure function, a KMP search that reports every occurrence and counts its comparisons, a Boyer-Moore search with the bad-character rule, and the two halves of running a nondeterministic finite automaton (NFA): the epsilon-closure of a set of states, and the set of states after reading a text. The starter has a self-running test battery; you fill in seven TODOs. The final exam (Wednesday Dec 16) covers this material.

Tasks

TODOFunctionWhat it must do
1insertStore a key in the trie, creating only the missing nodes, and return how many nodes it created.
2longestPrefixOfThe length of the longest stored key that is a prefix of a query, in one walk down the trie; -1 if there is none.
3failureThe KMP failure function of a pattern, built by matching the pattern against itself.
4kmpAllEvery occurrence of a pattern in a text, overlapping ones included, by the KMP scan, counting its character comparisons.
5bmSearchThe first occurrence by Boyer-Moore with the bad-character rule, counting its character comparisons.
6epsClosureEvery NFA state reachable from a set of states by epsilon-edges alone.
7statesAfterThe set of states the NFA of a regular expression can be in after reading a text.

The full contract of each function, with examples, is in the comment above it in the starter. The trie, the regular-expression construction (buildNFA) and accepts are given. The comparison counts in TODOs 4 and 5 must match the contract exactly. Every function is also tested on large inputs (texts of up to two million characters, a 300,000-state machine) with a time limit: write each one with the running time its contract states.

The tests run themselves

g++ -std=c++17 -O2 hw10.cpp -o hw10 && ./hw10

Each check prints [PASS] or [FAIL]. The unmodified starter compiles and fails most of them. The tries allocate memory: valgrind --leak-check=full ./hw10 should report no leaks (not graded).
