Homework 6: Directed Graphs and Shortest Paths

The full road network of the United States used in the 9th DIMACS Implementation Challenge on shortest paths has about 24 million vertices and 58 million edges. 9th DIMACS Implementation Challenge: Shortest Paths, 2006
At a glance
Covers: Lecture 10 (DFS and Topological Sort) and Lecture 11 (Dijkstra) Format: individual Language: C++17 Starter: hw06.cpp Submit: a .zip with your hw06.cpp Due: Sun Nov 8, 11:59 PM

Five functions: cycle detection with three colors, a topological order that always takes the smallest ready vertex, the strongly connected components by Kosaraju's two passes, Dijkstra's algorithm with a priority queue, and shortest paths in a DAG whose edges may have negative weights. The starter has a self-running test battery; you fill in five TODOs. The midterm (Monday Nov 9) covers this material too.

Tasks

TODOFunctionWhat it must do
1hasCycleDecide whether a digraph has a directed cycle, by looking for a back edge in a depth-first search.
2topoOrderMinA topological order by Kahn's algorithm, always outputting the smallest ready vertex; empty if there is a cycle.
3sccLabelsLabel the strongly connected components with Kosaraju's two depth-first passes.
4dijkstraShortest-path distances from s with nonnegative weights, using a priority queue with lazy deletion.
5dagShortestShortest-path distances in a DAG with possibly negative weights, relaxing edges in topological order.

The full contract of each function, with examples, is in the comment above it in the starter. Every function is also tested on graphs with 100,000 vertices and 1,000,000 edges, with a time limit: write each one with the running time its contract states. Keep the signature of dijkstra exactly as given; Programming Assignment 2 reuses it.

The tests run themselves

g++ -std=c++17 -O2 hw06.cpp -o hw06 && ./hw06

Each check prints [PASS] or [FAIL]. The unmodified starter compiles and fails most of them.

Build on the lab Code is graded on the CSS Linux lab with g++ -std=c++17. Build and run there at least once before you submit; the Computing Environment guide has the login and file-transfer commands. Code that does not compile on the lab receives no points.
