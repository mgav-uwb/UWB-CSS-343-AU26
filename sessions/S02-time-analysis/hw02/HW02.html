This homework applies the analysis tools of week 2 to cases the slides do not work out: the doubling experiment when the sizes do not double, a sort that removes a loop, witness constants for asymptotic claims, and the byte layout of a struct. The starter has a self-running test battery; you fill in five TODOs (the fourth has three parts). Quiz 2 (Monday Oct 12) asks about the same material.

Witnesses A witness is valid only if the inequality holds for every n ≥ n0, not only at the values you tried. Work it out on paper first, as on the slides, and write your reasoning as a comment in the function. The tests check every n from your n0 to 1,000,000.

The tests run themselves

g++ -std=c++17 -O2 hw02.cpp -o hw02 && ./hw02
  • T1, T2 the exponent and the prediction, on Lecture 2's 3-sum counts and on sizes that triple
  • T3 pairs with a given difference, including 200,000 values, which runs in well under a second when the algorithm is N log₂ N and takes far longer when it checks every pair
  • T4 each witness, checked for every n from n0 to 1,000,000
  • T5 the size of both structs

Each check prints [PASS] or [FAIL]. The unmodified starter compiles and fails almost all of them.

Build on the lab Code is graded on the CSS Linux lab with g++ -std=c++17. Build and run there at least once before you submit; the Computing Environment guide has the login and file-transfer commands. Code that does not compile on the lab receives no points.
