At a glance
Covers: Lecture 1 (Review of C++, Recursion, and Counting) Format: individual Language: C++17 Starter: hw01.cpp Submit: a .zip with your hw01.cpp Due: Sun Oct 4, 11:59 PM

This homework practices the three things Lecture 1 reviewed: a class that owns heap memory, recursion on a list and on an array, and counting how often a line of code runs. The starter gives the data structures, the loop version of 3-sum, and a self-running test battery. You fill in seven TODOs. Quiz 1 (Monday Oct 5) asks about the same material.

Tasks

TODOFunctionWhat it must do
1~IntList()Free every node the list owns.
2IntList(const IntList&)Build an independent copy: the same keys in the same order, in nodes of its own, with head, tail and count consistent.
3operator=Release the old nodes, then copy, leaving all three members consistent. Assigning a list to itself leaves it unchanged.
4sumThe sum of the keys in a chain. Recursive, no loops.
5occurrencesHow many nodes in a chain hold a given key. Recursive, no loops.
6lowerBoundIn a sorted array that may repeat keys, the first index whose element is at least the key (or one past the range if there is none). Recursive, halving the range each call, adding 1 to probes per comparison.
7findKEvery way to choose k elements from a[start..] that sum to a target, collected as lists of the chosen elements, adding 1 to checks each time a complete choice is tested.

Each task is a relative of code from Lecture 1, not a copy of it: the list keeps a tail and a count as well as a head, the search finds a position rather than a key, and the recursion reports the choices themselves rather than how many there are. The full contract of each function is in the comment above it in the starter.

The tests run themselves

g++ -std=c++17 -g hw01.cpp -o hw01 && ./hw01
  • T1 to T3 the Rule of Three, checked by counting the nodes that are alive and by checking that head, tail and count agree
  • T4, T5 sum and occurrences
  • T6 lowerBound: the right position, including the first of several equal keys, and the right number of probes (4 for the 15-key array of the lecture)
  • T7 findK: the exact choices, as many as the loop version counts, and the same number of checks (120, 1140 and 9880 at n = 10, 20 and 40)

Each check prints [PASS] or [FAIL]. The unmodified starter compiles and fails most of them. A crash at the end of T2 usually means two lists are sharing one chain of nodes.
