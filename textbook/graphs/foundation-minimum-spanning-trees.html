Minimum Spanning Trees: The Cut Property

Otakar Borůvka posed and solved the minimum spanning tree problem in 1926, to lay out an electrical network for Moravia at least cost. O. Borůvka, “O jistém problému minimálním,” Práce Moravské přírodovědecké společnosti 3, 1926

The minimum spanning tree is the cheapest way to wire a weighted graph so everything is connected. One theorem, the cut property, stands behind every algorithm that computes it: it says which edges are safe to take greedily, and one exchange argument proves it. This handout sets up the problem and the theorem; Kruskal’s algorithm and Prim’s algorithm put them to work.

1. Spanning trees and the MST problem

Definition (spanning tree, MST) A spanning tree of a connected graph is a subset of its edges that connects all \(V\) vertices with no cycle, necessarily exactly \(V-1\) edges. A minimum spanning tree (MST) of a connected, edge-weighted, undirected graph is a spanning tree of minimum total edge weight.

A spanning tree sits exactly at the connectivity boundary: remove any one of its edges and the graph falls into two pieces; add any one non-tree edge and you close exactly one cycle. (These are the “two of three” facts about {connected, acyclic, \(V-1\) edges} from the graph representations handout, now load-bearing.) A graph usually has exponentially many spanning trees; the MST is the cheapest.

The minimum weight is unique even when the tree is not If all edge weights are distinct, the MST is unique. If weights tie, several different edge sets may all be minimal, but every one of them has the same total weight, so “the MST weight” is always well-defined. The running graph below has all-distinct weights, so its MST is unique.

2. The running graph

The graph for this handout, and for the Kruskal and Prim traces, is the same eight vertices and eleven weighted edges as in the graph representations and Dijkstra handouts, only now undirected (the arrows are dropped). The question is no longer “cheapest routes from a source” but “cheapest set of edges connecting everything.”

3. The cut property

One theorem stands behind every MST algorithm. A cut is a partition of the vertices into two nonempty sets; an edge crosses the cut if its endpoints fall on opposite sides.

Theorem (cut property) For any cut, a minimum-weight edge crossing it belongs to some MST. (When weights are distinct, the minimum crossing edge belongs to every MST.)
Proof (exchange argument). Let \(e\) be a lightest edge crossing a given cut, and suppose some MST \(T\) does not contain \(e\). Adding \(e\) to \(T\) creates exactly one cycle (a fact from the graph representations handout), and that cycle starts and ends on the same side of the cut, so it must cross the cut a second time, by some other edge \(f\). Since \(e\) is a lightest crossing edge, \(w(f) \ge w(e)\). Now form \(T' = T - f + e\): removing \(f\) breaks the cycle, and \(e\) reconnects the two pieces, so \(T'\) is again a spanning tree, and its weight \(w(T') = w(T) - w(f) + w(e) \le w(T)\). But \(T\) was minimum, so \(w(T') = w(T)\): \(T'\) is also an MST, and it contains \(e\). ∎

Every MST algorithm is just a disciplined way to pick cuts and take their lightest crossing edge. This exchange argument (add the greedy choice, find the cycle it closes, swap out a no-better edge) is the template for greedy-optimality proofs (The Greedy Method), and we reuse it in Huffman Coding.

Example (a cut on the running graph) Split the vertices as \(\{0, 1\}\) versus \(\{2,3,4,5,6,7\}\). The crossing edges are \(1\text{-}2\,(1)\), \(1\text{-}3\,(5)\), \(0\text{-}3\,(6)\), and \(0\text{-}5\,(20)\). The lightest is \(1\text{-}2\) at weight \(1\), so it is safe, and indeed it is in the MST. This happens to be the very first edge Kruskal takes.
Example (the exchange step, worked) The proof is a swap; here is that swap performed, on the same cut \(S = \{0,1\}\) with \(e = 1\text{-}2\,(1)\). Take the spanning tree \[ T = \{0\text{-}1\,(4),\ 1\text{-}3\,(5),\ 2\text{-}3\,(8),\ 3\text{-}4\,(2),\ 4\text{-}5\,(3),\ 4\text{-}7\,(7),\ 5\text{-}6\,(9)\}, \quad w(T) = 38, \] which is a spanning tree (7 edges, connected, acyclic) but does not contain \(e\).
  1. Add \(e\). \(T + e\) has \(8\) edges on \(8\) vertices, so it holds exactly one cycle: \(1\text{-}2,\ 2\text{-}3,\ 3\text{-}1\).
  2. Find the second crossing. That cycle leaves \(S\) at \(e = 1\text{-}2\) and must come back, so some other edge of it crosses too: \(2\text{-}3\) has both ends outside \(S\), while \(f = 1\text{-}3\) has one end in \(S\). So \(f = 1\text{-}3\), weight \(5\).
  3. Check the inequality. \(w(f) = 5 \ge w(e) = 1\), as the minimality of \(e\) among crossing edges guarantees.
  4. Swap. \(T' = T - f + e = \{0\text{-}1,\ 1\text{-}2,\ 2\text{-}3,\ 3\text{-}4,\ 4\text{-}5,\ 4\text{-}7,\ 5\text{-}6\}\): still \(7\) edges, still connected (\(e\) rejoins the two pieces that deleting \(f\) made), still acyclic. Its weight is \(38 - 5 + 1 = 34 \le 38\).
The swap did not increase the weight, which is the whole content of the theorem: a spanning tree omitting the lightest crossing edge can always be traded for one containing it at no extra cost. Here the trade strictly improved things (\(34 < 38\)), which also proves \(T\) was not an MST.
Example (the equality case, when weights tie) The proof concludes \(w(T') \le w(T)\), with equality exactly when \(w(f) = w(e)\). That needs tied weights, which the running graph does not have, so take the four-cycle with all four weights equal to \(1\): 
  a –1– b        cut S = {a, b}
  |         |       crossing edges: b–c (1), d–a (1)     tied
  1         1       every 3 of the 4 edges is a spanning tree of weight 3,
  |         |       so all four spanning trees are MSTs
  d –1– c
Both crossing edges are minimum, so take \(e = d\text{-}a\). The MST \(T = \{a\text{-}b,\ b\text{-}c,\ c\text{-}d\}\), weight \(3\), omits \(e\). Adding \(e\) closes the cycle \(a\text{-}b\text{-}c\text{-}d\text{-}a\), which crosses the cut a second time at \(f = b\text{-}c\), and \(w(f) = 1 = w(e)\). The swap gives \(T' = \{a\text{-}b,\ c\text{-}d,\ d\text{-}a\}\) of weight \(3 - 1 + 1 = 3 = w(T)\): a different MST, and this one contains \(e\). This is why the theorem says a lightest crossing edge is in some MST rather than in every one; with distinct weights the inequality is strict and “some” strengthens to “every.”

The cycle property (the dual)

The mirror statement is equally useful, and is the same exchange run backwards. The cut property says what to add; the cycle property says what to skip. Kruskal uses both.

Theorem (cycle property) If an edge \(f\) is the unique maximum-weight edge on some cycle \(C\), then \(f\) belongs to no MST.
Proof (the exchange, run backwards). Suppose some MST \(T\) contains \(f = u\text{-}v\). Deleting \(f\) splits \(T\) into two components; let \(S\) be the one containing \(u\), so \(f\) crosses the cut \((S, V \setminus S)\). The rest of the cycle \(C\) is a path from \(u\) to \(v\); it starts inside \(S\) and ends outside it, so at least one of its edges \(g \ne f\) crosses that same cut. Since \(f\) is the strict maximum on \(C\), \(w(g) < w(f)\). Then \(T - f + g\) reconnects the two components and is again a spanning tree, of weight \(w(T) - w(f) + w(g) < w(T)\), contradicting the minimality of \(T\). So no MST contains \(f\). ∎

One generic algorithm, three instances Cormen et al. present Kruskal and Prim as two settings of a single generic MST algorithm: maintain a set of edges \(A\) that is always a subset of some MST, and repeatedly add a safe edge: a minimum-weight edge crossing a cut that \(A\) does not already cross. The cut property is exactly the guarantee that such an edge is safe. The three classic algorithms differ only in which cut they take at each step:
  • Kruskal: the cut around the two components its next edge would join (\(A\) is a growing forest);
  • Prim: the cut of the one growing tree versus everything else;
  • Borůvka: every component’s cheapest outgoing edge, all added at once each round.
Recognizing the shared skeleton means one theorem, the cut property, proves all three at once.

4. Computing the MST: the algorithms

Two handouts put the cut property to work. Kruskal’s algorithm considers edges from cheapest to most expensive and accepts each one that joins two so-far-separate pieces; it is exactly a sort plus union-find. Prim’s algorithm grows one tree from a start vertex, always by the lightest edge leaving it, kept in a binary heap. Both find the tree of weight \(31\) on the running graph.

The third algorithm: Borůvka (1926) The oldest MST algorithm, and the one that parallelizes best. Each round, every current component simultaneously selects its own cheapest outgoing edge and all selected edges are added at once; since every component at least halves in number per round (each merges with at least one neighbor), only \(O(\log V)\) rounds are needed, each an \(\Theta(E)\) scan, for \(O(E\log V)\) overall. Every selected edge is safe by the cut property (it is the lightest edge crossing its component’s cut), so correctness is free. Because the components act independently within a round, Borůvka is the basis of parallel and distributed MST algorithms, and, combined with Prim, of the fastest known near-linear sequential ones.

Minimum spanning trees themselves are the workhorse behind cheapest-network design (cabling, roads, pipelines that reach every site) and, with one twist, clustering: build the MST of a set of data points under distance weights, then delete the \(k-1\) heaviest tree edges, and the tree falls into \(k\) clusters: single-linkage clustering, from the same algorithm that wires a network. Elsewhere in the course, the leverage comes from combining known structures, not inventing new ones; The Greedy Method and Huffman Coding push exactly this idea further.

5. Exercises (with solutions)

  1. A graph has a unique lightest edge \(e\). Prove \(e\) is in every MST.
    solution Take any cut with \(e\) crossing it, for instance the cut separating one endpoint of \(e\) from the other. Every crossing edge other than \(e\) is strictly heavier (since \(e\) is the unique global minimum), so \(e\) is the minimum crossing edge of that cut, and by the cut property it belongs to every MST. (More generally, the globally lightest edge is always safe to take first, which is exactly Kruskal’s opening move.)
  2. On the running graph, take the cut \(S = \{0,1,2,3\}\) against \(\{4,5,6,7\}\). List the crossing edges, name the safe one, and then run the exchange on the spanning tree \(T = \{0\text{-}1,\ 1\text{-}2,\ 1\text{-}3,\ 3\text{-}7,\ 4\text{-}7,\ 4\text{-}5,\ 5\text{-}6\}\), which omits it.
    solution The crossing edges are \(3\text{-}4\,(2)\), \(3\text{-}7\,(11)\), and \(0\text{-}5\,(20)\); every other edge has both ends on one side. The lightest is \(e = 3\text{-}4\,(2)\), so it is safe, and it is indeed in the tree of §2. Now the exchange: \(w(T) = 4+1+5+11+7+3+9 = 40\). Adding \(e = 3\text{-}4\) closes the single cycle \(3\text{-}4,\ 4\text{-}7,\ 7\text{-}3\); of its edges, \(4\text{-}7\) lies wholly outside \(S\), so the second crossing edge is \(f = 3\text{-}7\,(11)\), and \(w(f) = 11 \ge w(e) = 2\). Swapping, \(T' = T - f + e\) has weight \(40 - 11 + 2 = 31\): a spanning tree, no heavier, containing \(e\). (It is in fact the MST.)
  3. Edge \(4\text{-}7\) has weight \(7\), heavier than \(0\text{-}3\)’s \(6\), yet \(4\text{-}7\) is in the MST and \(0\text{-}3\) is not. Justify both facts, one with each property. What does the pair show about judging an edge by its weight alone?
    solution Vertex \(7\) has exactly two incident edges, \(4\text{-}7\,(7)\) and \(3\text{-}7\,(11)\). Take the cut \(\{7\}\) against everything else: those two are the crossing edges, and the lighter is \(4\text{-}7\), so by the cut property \(4\text{-}7\) is in every MST (the weights are distinct). For \(0\text{-}3\): it is the strict maximum on the cycle \(0\text{-}1\,(4),\ 1\text{-}3\,(5),\ 0\text{-}3\,(6)\), so by the cycle property it is in no MST. Weight alone decides nothing: what matters is an edge’s weight relative to the alternatives on the cut or cycle it sits on. A heavy edge is kept when it is the only affordable way to reach a vertex, and a light edge is dropped when a cycle already provides a cheaper route.
