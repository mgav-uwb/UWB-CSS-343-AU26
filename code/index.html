Code Library

Reusable C++ for experiments and homework: small utilities, measurement programs, and every program the lectures run. Assignment starters live with their assignments, not here.

Utilities

Headers to copy into a program. Each one's comment says how to use it. Build anything here with g++ -std=c++17 -O2 file.cpp -o file; each header works on its own.

filewhat it gives you
rng.ha random number generator that produces the same sequence with every compiler, plus between(lo, hi) and shuffle(v). The standard library's distributions differ between g++ and clang, so the same seed can give different data
timer.hStopwatch on a clock that never jumps, and fastestOf(reps, f), the fastest of several runs
alloc_counter.hcounts every byte and block allocated with new, by replacing the global operator new; include it in exactly one .cpp file
example.cppall three in one short program
#include "rng.h"
#include "timer.h"
#include "alloc_counter.h"          // in exactly one .cpp file

Rng r(343);
std::vector<int> v(1000000);
for (int& x : v) x = (int)r.between(-1000000, 1000000);
double t = fastestOf(5, [&] { w = v; std::sort(w.begin(), w.end()); });
AllocStats before = allocStats();
std::vector<int> a(1000);
long long bytes = (allocStats() - before).bytes;   // 4000

Measurement

Programs that measure the machine rather than an algorithm. They back the numbers in the Computer Systems Primer, and the first two also run in the browser as Memory Hierarchy, Measured.

filewhat it measures
latency.cppthe time for one dependent memory read, as the array grows past each cache: about 1.4 ns in L1 to 100 ns in main memory
locality.cppthe same additions in two orders: a matrix by rows and by columns, a linked list in memory order and scattered
optimize.cpp3-sum at -O0 and -O2, and a loop the optimizer deletes because its result is never used
