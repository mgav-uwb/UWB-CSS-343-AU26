The Doubling Experiment, Measured

Three algorithms for 3-sum, run in your browser on the same arrays (distinct random integers, fixed seed). Each row doubles N. The count is exact and the same on every machine; the time is your machine’s. Their ratios when N doubles reveal the exponent.

Press Run. Each size doubles the last; a size that would take longer than the time budget is skipped.
algNcountratiotime (ms)ratiolog₂ ratio

What is counted. Brute force: triples tested, exactly N(N−1)(N−2)/6. Binary search: probes, one per pass of the search loop, at most ⌊log₂ N⌋ + 1 per pair. Two pointers: iterations of the pointer loop, at most (N−1)(N−2)/2.

Reading the ratios. For a cost a·Nb the ratio T(2N)/T(N) is 2b, so log₂ ratio is the exponent b: about 3, 2 and 2. Binary search sits a little above 2 because its log₂ N factor grows too. The slope on the log-log plot is the same b, fitted to the last three points.

The C++ versions are topics/code/analysis-doubling/threesum.cpp and topics/code/faster-3sum/twopointer.cpp. JavaScript is slower than -O2 C++ by a constant factor, which the ratios cancel.
