Machine Models, Simulated

A doubling experiment on a machine you choose. Nothing here is timed: the cost of every step comes from a model of the machine’s memory levels, so the numbers are exact for the model and the same on every computer. Change the machine or the access pattern and watch where the doubling ratio stops being 2b.

edit the machine’s memory levels

Capacity in bytes (accepts 32K, 16M, 4G, inf), time per access in the machine’s unit, block = bytes handed to the level above on a miss. Levels are listed fastest first; the last one is unbounded.

How to read it

Each row doubles N. The ratio is the cost at this N divided by the cost at half this N, and b = log₂(ratio) is the local exponent. For an algorithm whose cost in the RAM model is Θ(Nb), the ratio is 2b while the working set stays in one memory level. In the doubling where the working set outgrows a level, the cost of one access rises, and the local exponent becomes b + log₂(new cost per access / old cost per access): highlighted in red. After the crossing it returns to b, because the slower level also costs a constant per access. The dashed line in the chart has the RAM-model slope through the first point.

The model. A machine is a list of levels, fastest first, each with a capacity, a time per access and a block size. A sequential scan of a working set of W bytes held at level k fetches each block once from level k: one access costs the top level’s time plus level k’s time times (item size / block size). Random accesses over W bytes find their data at level k with probability min(1, Ck/W) minus the same for the level above, the steady state of random replacement and close to least-recently-used (LRU) replacement. This analytical model is used instead of simulating every access because the effects worth seeing happen at N beyond 109, where N2 accesses cannot be simulated one by one.

The machines. The laptop uses the latencies measured in the Computer Systems Primer (1.4 ns, about 4, 15 and 100 ns) and a typical 50 µs for its solid-state drive (SSD). The small machine has 64 MiB of memory and swaps to a hard disk with a 5 ms access time. The million-cycle machine charges 106 cycles for every memory access: its ratios never change.
